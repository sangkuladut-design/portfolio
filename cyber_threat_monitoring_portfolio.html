Project 1: Suspicious Login Activity Investigation

Project type: Simulated training project

Objective

Review security logs in Splunk to identify repeated failed login attempts that may indicate suspicious authentication activity.

Sample Splunk Search

index=lab EventCode=4625
| stats count by user, src_ip
| sort - count

Note: The index and field names must match the data in your Splunk lab. Adjust them as needed.

Investigation Steps

  1. Search security event logs in Splunk.
  2. Filter for failed login events, commonly associated with Windows Event ID 4625.
  3. Review available usernames, source IP addresses, timestamps, and event counts.
  4. Look for repeated failures that could indicate a brute-force attempt.
  5. Document findings and recommend next steps.

Sample Findings

Repeated failed login attempts associated with an account and source address may indicate a brute-force attempt. Additional evidence is needed before confirming malicious activity.

Recommendations

  • Review the source IP and related security events.
  • Check for successful logins after repeated failures.
  • Escalate suspicious activity according to the organization's procedures.
  • Document the investigation and preserve relevant logs.
